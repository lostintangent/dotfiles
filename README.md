# 💠 lostintangent's dotfiles

This is where I'll be maintaining my shell scripts, and re-usable agent skills/commands/etc.

## Contents

| File | Description |
|------|-------------|
| `.zshrc` | Zsh shell configuration: completion, git-aware prompt, syntax highlighting, auto-suggestions, and `$PATH` setup for tools like `fnm`, `bun`, `omnara`, and `antigravity` |
| `.tmux.conf` | Tmux configuration: `Ctrl-a` prefix, mouse support, vim-style pane navigation, 1-based window/pane indexing, and a minimal status bar |
| `.gitconfig` | Git user identity and credential helper wired to the `gh` CLI |
| `.oshen_floor` | [Oshen](https://github.com/nicholasgasior/oshen) shell profile — sets `$PATH`, Homebrew/NVM/omnara env vars, and defines a `cls` alias |
| `.gitignore` | Repo-level gitignore |
