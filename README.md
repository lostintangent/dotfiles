# 💠 lostintangent's dotfiles

This is where I'll be maintaining my shell scripts, and re-usable agent skills/commands/etc.

## 🐚 Shell

The [`.zshrc`](.zshrc) file configures Zsh with the following:

- 🔍 **Completion** - Menu-based tab completion with case-insensitive matching
- 🌿 **Git-aware prompt** - Displays the current branch in the shell prompt
- ✨ **Auto-suggestions** - Suggests commands based on history via `zsh-autosuggestions`
- 🎨 **Syntax highlighting** - Highlights commands as you type via `zsh-syntax-highlighting`

## 🔧 Git

The [`.gitconfig`](.gitconfig) file configures Git with the following:

- 👤 **User info** - Name and email for commits
- 🔑 **Credentials** - Uses the `gh` CLI for GitHub authentication

## 🌊 Environment

The [`.oshen_floor`](.oshen_floor) file configures the environment with the following:

- 🍺 **Homebrew** - Sets up Homebrew paths and environment variables
- 📦 **Node.js** - Configures NVM and Node.js paths
- 🛤️ **PATH** - Adds custom tool paths for Omnara, Homebrew, and local binaries
